# Guía de uso (3c-3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Consejos en el momento dentro del Lector (una tarjeta abajo, uno a la vez, una sola vez cada uno), Biblioteca vacía con cómo añadir y dónde conseguir libros gratis, y una pantalla "Cómo se usa" desde la Biblioteca y desde la hoja Aa.

**Architecture:** Las marcas "ya visto" se guardan en `AppSettings` (SharedPreferences) y se publican como `StateFlow`. Unas reglas puras (`TipRules`) deciden qué consejo toca según el estado del Lector; el `ReaderViewModel` las combina con sus eventos y expone `tip: StateFlow<TipId?>`; la pantalla dibuja `TipCard` sobre la barra inferior. "Cómo se usa" es una pantalla sin estado: ruta nueva en la app y capa a pantalla completa en el Lector (como "Idiomas").

**Tech Stack:** Kotlin, Jetpack Compose Material 3, Navigation 3 (`NavDisplay`), Readium 3.4 (navegador WebView), JUnit/kotlin.test + coroutines-test (JVM), AndroidX Test + Compose UI test (Pixel).

**Spec:** `docs/superpowers/specs/2026-10-15-guia-uso-3c3-design.md`

## Review Focus

1. Persona que ya usó la app (consejos ya vistos) abre un libro: no debe parpadear ningún consejo mientras se leen los ajustes del disco → `TipRules.next` devuelve null hasta `seenLoaded` (prueba en Tarea 1 y en el VM, Tarea 3).
2. Dos consejos elegibles a la vez (libro en español, modo Tocar, nunca tocado): sale DIRECTION, y TAP espera; un consejo ya en pantalla no lo reemplaza otro de mayor prioridad que se vuelve elegible después (pegajoso) → Tarea 1.
3. Hoja abierta (Aa, Índice, dirección), "Idiomas", "Cómo se usa" o banda del aviso visibles: la tarjeta no se muestra y al cerrarlas vuelve el mismo consejo → Tarea 1 (`blocked`) y Tarea 3 (pantalla).
4. Ajuste `tips_seen` dañado (otro tipo o ids desconocidos): se trata como vacío o se ignoran los desconocidos, sin cierre → Tarea 1.
5. Teléfono sin navegador: tocar "Project Gutenberg" no cierra la app → Tarea 4 (`openExternal` con `ActivityNotFoundException`, prueba JVM con un `Context` falso que lanza).

```kotlin
package io.github.diegobr4nd.lectorbilingue.data

/**
 * Los consejos del Lector (3c-3). El orden es la prioridad: si dos tocan a la vez, sale el primero.
 * [wire] es lo que se guarda en el teléfono: no cambiarlo (un consejo ya visto volvería a salir).
 */
enum class TipId(val wire: String) {
    DIRECTION("direction"),
    TAP("tap"),
    HIDE_AND_MODES("hide_modes"),
    CHAPTER_EDGE("chapter_edge"),
    ;

    companion object {
        fun fromWire(value: String): TipId? = entries.firstOrNull { it.wire == value }
    }
}
```

En `AppSettings` (junto a los ajustes de lectura, mismo estilo):

```kotlin
    private val tipsState = MutableStateFlow<Set<TipId>>(emptySet())
    private val tipsLoaded = MutableStateFlow(false)

    /** Los consejos ya vistos (3c-3). Vacío hasta que [seenTipsLoaded] sea true. */
    val seenTipsFlow: StateFlow<Set<TipId>> = tipsState.asStateFlow()

    /** true cuando [seenTipsFlow] ya tiene lo guardado: antes, ningún consejo se muestra (no parpadean). */
    val seenTipsLoaded: StateFlow<Boolean> = tipsLoaded.asStateFlow()

    /** Lee los consejos vistos fuera del hilo principal y los publica. Repetirla no hace nada. */
    suspend fun loadSeenTips(io: CoroutineDispatcher = Dispatchers.IO) {
        if (tipsLoaded.value) return
        val stored = withContext(io) { readTips() }
        // Si mientras tanto se marcó uno, se suma a lo guardado.
        synchronized(tipsState) { if (!tipsLoaded.value) tipsState.value = stored + tipsState.value }
        tipsLoaded.value = true
    }

    /** Marca [id] como visto (no vuelve a salir). */
    fun markTipSeen(id: TipId) {
        synchronized(tipsState) {
            val all = (if (tipsLoaded.value) tipsState.value else readTips() + tipsState.value) + id
            prefs.edit { putString(KEY_TIPS, all.joinToString(",") { it.wire }) }
            tipsState.value = all
            tipsLoaded.value = true
        }
    }

    /** "Volver a ver los consejos": borra todas las marcas. */
    fun resetTips() {
        synchronized(tipsState) {
            prefs.edit { remove(KEY_TIPS) }
            tipsState.value = emptySet()
            tipsLoaded.value = true
        }
    }

    // Ilegible (otro tipo) → nada visto: en el peor caso un consejo sale otra vez. Ids desconocidos se ignoran.
    private fun readTips(): Set<TipId> =
        safeString(KEY_TIPS)?.split(',')?.mapNotNull { TipId.fromWire(it.trim()) }?.toSet() ?: emptySet()
```

```kotlin
package io.github.diegobr4nd.lectorbilingue.ui.tips

import io.github.diegobr4nd.lectorbilingue.data.ReadingMode
import io.github.diegobr4nd.lectorbilingue.data.TipId

/**
 * Lo que las reglas necesitan saber del Lector.
 * [seenLoaded]: los vistos ya se leyeron del disco (antes no sale nada, así no parpadea un consejo ya visto).
 * [pageReady]: hay página del libro. [blocked]: hay una hoja, "Idiomas", "Cómo se usa" o la banda del aviso.
 * [translatedByTap]: en esta sesión un toque mostró una traducción. [reachedChapterEnd]: la lectura llegó al final de
 * un capítulo que no es el último.
 */
data class TipState(
    val seen: Set<TipId>,
    val seenLoaded: Boolean,
    val pageReady: Boolean,
    val blocked: Boolean,
    val mode: ReadingMode,
    val sourceIsSpanish: Boolean,
    val translatedByTap: Boolean,
    val reachedChapterEnd: Boolean,
)

/** Lo que hace la persona y puede cerrar el consejo en pantalla. */
enum class TipEvent { TAPPED, CARD_HIDDEN, SETTINGS_OPENED, DIRECTION_OPENED, CHAPTER_CHANGED }

/** Reglas puras de los consejos (spec 3c-3 §3): uno a la vez, una sola vez cada uno. */
object TipRules {
    /**
     * El consejo que se ve ahora, o null. [current] es el que ya estaba en pantalla: se queda mientras siga elegible y
     * sin ver (otro que se vuelva elegible después espera su turno).
     */
    fun next(state: TipState, current: TipId?): TipId? {
        if (!state.seenLoaded || !state.pageReady || state.blocked) return null
        if (current != null && current !in state.seen && eligible(current, state)) return current
        return TipId.entries.firstOrNull { it !in state.seen && eligible(it, state) }
    }

    /** ¿[event] cierra (y marca visto) a [tip]? Solo cuenta para el consejo que está en pantalla. */
    fun dismissedBy(tip: TipId, event: TipEvent): Boolean = when (tip) {
        TipId.DIRECTION -> event == TipEvent.DIRECTION_OPENED
        TipId.TAP -> event == TipEvent.TAPPED
        TipId.HIDE_AND_MODES -> event == TipEvent.CARD_HIDDEN || event == TipEvent.SETTINGS_OPENED
        TipId.CHAPTER_EDGE -> event == TipEvent.CHAPTER_CHANGED
    }

    private fun eligible(tip: TipId, s: TipState): Boolean = when (tip) {
        TipId.DIRECTION -> s.sourceIsSpanish
        TipId.TAP -> s.mode == ReadingMode.TAP && !s.translatedByTap
        TipId.HIDE_AND_MODES -> s.mode == ReadingMode.TAP && s.translatedByTap
        TipId.CHAPTER_EDGE -> s.reachedChapterEnd
    }
}
```

```kotlin
package io.github.diegobr4nd.lectorbilingue.ui.tips

/**
 * Consejo del Lector (spec 3c-3 §4): bombilla + texto entero + "Entendido" (≥ 48 dp). Colores de la app (no de la
 * página), así se lee igual en los 4 temas. TalkBack: el texto es una región viva (se dice una vez al aparecer); el
 * botón va aparte. Con letra ≥ 150 % el botón baja debajo del texto. Sin estado: se previsualiza sola.
 */
@Composable
fun TipCard(text: String, onDismiss: () -> Unit, modifier: Modifier = Modifier) {
    val colors = MaterialTheme.colorScheme
    val largeText = LocalDensity.current.fontScale >= LargeTipFontScale
    Surface(
        color = colors.secondaryContainer,
        contentColor = colors.onSecondaryContainer,
        shape = MaterialTheme.shapes.medium,
        border = BorderStroke(1.dp, colors.outlineVariant),
        modifier = modifier.fillMaxWidth().padding(horizontal = Spacing.m, vertical = Spacing.s),
    ) {
        val message = @Composable { m: Modifier ->
            Row(
                m.clearAndSetSemantics {
                    contentDescription = text
                    liveRegion = LiveRegionMode.Polite
                },
                verticalAlignment = Alignment.CenterVertically,
                horizontalArrangement = Arrangement.spacedBy(Spacing.m),
            ) {
                Icon(painterResource(LectorIcons.Lightbulb), contentDescription = null, modifier = Modifier.size(24.dp))
                Text(text, style = MaterialTheme.typography.bodyMedium)
            }
        }
        val button = @Composable {
            TextButton(
                onClick = onDismiss,
                colors = ButtonDefaults.textButtonColors(contentColor = colors.onSecondaryContainer),
                modifier = Modifier.heightIn(min = 48.dp),
            ) { Text(stringResource(R.string.tip_got_it), style = MaterialTheme.typography.labelLarge) }
        }
        val inner = Modifier.padding(start = Spacing.l, end = Spacing.s, top = Spacing.xs, bottom = Spacing.xs)
        if (largeText) {
            Column(inner) {
                message(Modifier.fillMaxWidth().padding(vertical = Spacing.s))
                Box(Modifier.fillMaxWidth(), contentAlignment = Alignment.CenterEnd) { button() }
            }
        } else {
            Row(inner, verticalAlignment = Alignment.CenterVertically) {
                message(Modifier.weight(1f).padding(vertical = Spacing.s))
                button()
            }
        }
    }
}
```

```kotlin
    private val pageShown = MutableStateFlow(false)
    private val tipBlocked = MutableStateFlow(false)
    private val tapTranslated = MutableStateFlow(false)
    private val chapterEnd = MutableStateFlow(false)
    private var shownTip: TipId? = null // el que está en pantalla: se queda hasta cerrarse (TipRules.next)

    /** El consejo que la pantalla muestra ahora, o null (spec 3c-3 §3). */
    val tip: StateFlow<TipId?> = combine(
        combine(settings.seenTipsFlow, settings.seenTipsLoaded, pageShown, tipBlocked) { seen, loaded, page, blocked ->
            arrayOf<Any>(seen, loaded, page, blocked)
        },
        combine(settings.readingSettingsFlow, _direction, tapTranslated, chapterEnd) { reading, dir, tapped, end ->
            arrayOf<Any>(reading.mode, dir, tapped, end)
        },
    ) { a, b ->
        @Suppress("UNCHECKED_CAST")
        val state = TipState(
            seen = a[0] as Set<TipId>, seenLoaded = a[1] as Boolean, pageReady = a[2] as Boolean, blocked = a[3] as Boolean,
            mode = b[0] as ReadingMode, sourceIsSpanish = (b[1] as LanguagePair).source == "es",
            translatedByTap = b[2] as Boolean, reachedChapterEnd = b[3] as Boolean,
        )
        TipRules.next(state, shownTip).also { if (!state.blocked) shownTip = it }
    }.stateIn(viewModelScope, SharingStarted.Eagerly, null)

    /** "Entendido": el consejo en pantalla queda visto. */
    fun dismissTip() {
        tip.value?.let { settings.markTipSeen(it) }
    }

    /** Algo que hizo la persona: si cierra el consejo en pantalla, queda visto (TipRules.dismissedBy). */
    fun onTipEvent(event: TipEvent) {
        val current = tip.value ?: return
        if (TipRules.dismissedBy(current, event)) settings.markTipSeen(current)
    }

    /** La lectura llegó al final de un capítulo que no es el último (lo mide la pantalla al asentarse). */
    fun onChapterEnd() { chapterEnd.value = true }

    /** Hay una hoja, "Idiomas", "Cómo se usa" o la banda del aviso: el consejo espera (no se marca). */
    fun setTipBlocked(blocked: Boolean) { tipBlocked.value = blocked }
```

```kotlin
package io.github.diegobr4nd.lectorbilingue.ui.tips

const val GUTENBERG_URL = "https://www.gutenberg.org"
const val STANDARD_EBOOKS_URL = "https://standardebooks.org"

/**
 * Abre [url] en el navegador del teléfono. La app no se conecta: lo hace el navegador. Sin navegador → false y nada
 * más (el nombre de la página queda escrito para buscarlo a mano).
 */
fun openExternal(context: Context, url: String): Boolean = try {
    context.startActivity(Intent(Intent.ACTION_VIEW, Uri.parse(url)).addFlags(Intent.FLAG_ACTIVITY_NEW_TASK))
    true
} catch (_: ActivityNotFoundException) {
    false
}

/**
 * "¿No tienes libros?" + dos botones de texto (≥ 48 dp) a Project Gutenberg y Standard Ebooks. Botones y no enlaces
 * dentro del texto: Compose no tiene rol de enlace y un enlace en línea no llega a 48 dp; TalkBack dice
 * "Abrir Project Gutenberg en el navegador, botón".
 */
@Composable
fun FreeBooks(modifier: Modifier = Modifier) {
    val context = LocalContext.current
    Column(modifier, horizontalAlignment = Alignment.CenterHorizontally) {
        Text(
            stringResource(R.string.free_books_intro),
            style = MaterialTheme.typography.bodyMedium,
            color = MaterialTheme.colorScheme.onSurfaceVariant,
            textAlign = TextAlign.Center,
        )
        FlowRow(horizontalArrangement = Arrangement.spacedBy(Spacing.s, Alignment.CenterHorizontally)) {
            for ((name, url) in listOf(R.string.free_books_gutenberg to GUTENBERG_URL, R.string.free_books_standard to STANDARD_EBOOKS_URL)) {
                val label = stringResource(name)
                val desc = stringResource(R.string.free_books_open_desc, label)
                TextButton(
                    onClick = { openExternal(context, url) },

            }
        }
    }
```
